### 2. Edge fingerprint — `microsoft edge` false positives

`fingerprint()` builds a lowercase blob from exec + name + id + wmClass only
(`discovery.cpp:333-336`). The new check mirrors the existing `google chrome`
pattern:

```454:456:src/core/discovery.cpp
    if (blob.contains(QLatin1String("microsoft-edge")) || blob.contains(QLatin1String("microsoft edge"))
        || blob.contains(QLatin1String("msedge"))) {
        chromium(QStringLiteral("Edge"), QStringLiteral("microsoft-edge"));
```

**Risk: low.** A false positive requires another desktop entry whose combined
exec/name/id/wmClass contains the substring `microsoft edge` without being
Edge. Flatpak Edge uses `Name=Microsoft Edge`, which previously missed
`microsoft-edge` and fell through to generic. No test added for the spaced
variant; existing flatpak discovery tests cover the machinery.
